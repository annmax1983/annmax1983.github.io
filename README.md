# Hey, I'm AnnMax 👋

I'm a full-stack developer who's been writing code since 2008 — back when IE6 was still a thing and jQuery felt like magic.

## The Journey

I started with .NET desktop apps and enterprise Java systems. Moved through Python data pipelines. Watched the web evolve from table layouts to CSS Grid, from jQuery to React, from "please upgrade your browser" to PWAs.

18 years later, I build browser extensions. Lightweight ones. Privacy-first ones. The kind that do one thing well and stay out of your way.
