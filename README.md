# AnnMax - Portfolio

80后全栈程序员个人主页 · 支持6国语言自动切换

## Features

- 🌍 6语言支持（中/英/西/德/日/法），根据浏览器自动切换
- 🎨 深色主题 + 玻璃拟态 + 渐变配色
- ✨ 粒子动画 + 滚动渐显 + 技能进度条
- 📱 完全响应式，移动端适配
- ⚡ 纯 HTML/CSS/JS，零依赖，加载极快

## Tech Stack

- HTML5
- CSS3 (Grid, Flexbox, Animations, Glassmorphism)
- Vanilla JavaScript (IntersectionObserver, i18n)

## Sections

1. **Hero** - 打字效果轮播标题
2. **About** - 20年编程经历 + 数字动画
3. **Skills** - 技能栈进度条
4. **Extensions** - 8款浏览器插件卡片展示
5. **Custom Dev** - 定制开发服务（核心CTA）
6. **Contact** - 联系方式

## Deploy

纯静态站点，可直接部署到 GitHub Pages / Gitee Pages / Vercel / Netlify。
