# Hey, I'm AnnMax 👋

I'm a full-stack developer who's been writing code since 2008 — back when IE6 was still a thing and jQuery felt like magic.

## The Journey

I started with .NET desktop apps and enterprise Java systems. Moved through Python data pipelines. Watched the web evolve from table layouts to CSS Grid, from jQuery to React, from "please upgrade your browser" to PWAs.

18 years later, I build browser extensions. Lightweight ones. Privacy-first ones. The kind that do one thing well and stay out of your way.

## What I Build

I maintain **17 browser extensions** for Chrome and Edge — all local-first: no analytics, no tracking, no accounts, and none of them uploads your content to us. A few features make their own network requests: license checks for paid plans, image fetches when you convert or batch-download, Link Audit requests to links you choose, and sync through your browser account (JustFocus by default; Premium sync in LiteCopy, StylePatch, LocalBox2FA and VKT Form):

- 📸 **PageShot** — Full-page screenshots with annotation
- 🖼️ **ImageConv** — Image format conversion (PNG/JPG/WEBP/AVIF)
- 🎨 **StylePatch** — Per-site CSS customization
- 📦 **ImageGrabber** — Batch image downloader (30 per batch free)
- 🔓 **LiteCopy** — Restores text selection and copying on sites that block it (unlimited free; Premium syncs site rules across devices)
- 🔐 **LocalBox2FA** — Local-first TOTP authenticator; encrypted cross-device sync is Premium
- 📊 **TableGrab** — HTML table to Excel (XLSX) / CSV exporter with preview, column selection and TSV/Markdown copy
- 🔤 **FontFixer** — Web font optimizer (5 sites free, unlimited with a license)
- 🎯 **JustFocus** — Site blocker with timed blocks; Surgical Blocking hides Shorts/Reels/For You feeds (YouTube Shorts free, 11 more sites with a license)
- 🔄 **RefreshMate** — Auto page refresher
- 🔗 **LinkHarvest** — Link extractor: copy as URLs, Markdown, HTML or JSON Lines; free TXT/JSON/CSV export; Link Audit flags broken links (100 free, 2,000 with a license)
- ⏱️ **RetroTime** — Floating timer widget (stopwatch / countdown / Pomodoro; custom colors with a license)
- 🌐 **VKT Header** — Domain-matched HTTP header modifier (5 rules free; rules apply to every tab) with a request tester
- 📝 **VKT Note** — Markdown note-taking with text selection (3 notes/day free)
- 📝 **VKT Form** — Form snapshot & auto-fill (unlimited local snapshots, fills and JSON export/import free; Premium adds cross-device sync)
- ⌨️ **VKT Shortcut** — Page shortcut blocker with per-site presets (20 rules free)
- 📌 **ItemPin** — Product saver & price history (50 items free; Premium unlimited, CSV export and comparison charts)

I also build **VKT PWA** — 9 installable web apps that run offline, installed straight from the browser:

- 🧮 **Tally** — Tap counter with live ratio
- 🖥️ **Screen** — Full-screen solid colours to spot dead pixels
- 🫧 **Pop** — Infinite bubble wrap
- 🍃 **Bloom** — Sweep fallen leaves, grow a garden
- ✂️ **Slice** — Draw a line, cut it in half
- 🪟 **Shatter** — Tap the glass, watch it crack and collapse
- ⏳ **Sand** — Draw with falling sand
- 🌀 **Flow** — Ink swirls through still water
- 💧 **Ripple** — One drop, spreading ripples

And on the SaaS side: **CertTrack Pro** — a multi-tenant reminder platform for certificate expiry tracking, equipment maintenance (CMMS) and inspection tasks, with automatic deadline reminders.
