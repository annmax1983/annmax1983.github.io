Chrome Extension Architecture: A Deep Dive into Manifest V3

July 2026

Introduction

Chrome extensions have evolved significantly with Manifest V3 (MV3). Understanding MV3 architecture is essential — it's a fundamental shift in how extensions operate.

This guide covers the core architectural components, based on the official Chrome Extensions documentation.

The Four Pillars of MV3

1. Service Worker (Background Script)

MV3 replaces the persistent background page with a service worker:

  • Ephemeral lifecycle — Starts when needed, terminates after ~30 seconds of inactivity
  • No DOM access — Cannot use document, window, or DOM-dependent Web APIs
  • Event-driven — Register listeners at the top level; they survive termination
// background.js
chrome.runtime.onInstalled.addListener(() => {
  chrome.contextMenus.create({
    id: 'my-action',
    title: 'My Action',
    contexts: ['page']
  });
});
chrome.contextMenus.onClicked.addListener((info, tab) => {
  // Handle — survives worker termination
});

Key rule: Use chrome.alarms instead of setTimeout — timers are cleared when the worker terminates.

2. Content Scripts

Content scripts run in web page contexts, in an isolated world:

  • Share the DOM with the page but have separate JavaScript contexts
  • Can use a subset of Chrome APIs (chrome.storage, chrome.runtime)
  • Static (manifest) or dynamic (chrome.scripting.executeScript) injection
await chrome.scripting.executeScript({
  target: {{ tabId: tab.id }},
  func: () => {{ document.body.style.backgroundColor = '#f0f0f0'; }}
});

3. Offscreen Documents

For DOM-dependent operations (clipboard, canvas, parsing) in MV3:

  • Clipboard — Copy images/text (requires DOM)
  • Canvas — Image processing, stitching, cropping
  • Parsing — DOMParser operations
await chrome.offscreen.createDocument({{
  url: 'offscreen.html',
  reasons: ['CLIPBOARD'],
  justification: 'Copy image to clipboard'
}});

4. Message Passing

Communication between components:

  • One-time — chrome.runtime.sendMessage()
  • Long-lived — chrome.runtime.connect()
  • Tab messaging — chrome.tabs.sendMessage()
